# Wortwerk content

Stories in `stories/` are beginner retellings of public-domain folk tales, written for the app.

Compiled JSON in `compiled/` and audio in `audio/` are generated by the ingestion pipeline on the author’s machine and committed so contributors can run the app without an LLM API key.

## Lexicon data

Word and phrase metadata in each story’s embedded lexicon is derived from [Wiktionary](https://en.wiktionary.org/), via [Wiktextract](https://github.com/tatuylonen/wiktextract) machine-readable exports on [kaikki.org](https://kaikki.org/). Wiktionary text is dual-licensed under [CC BY-SA](https://creativecommons.org/licenses/by-sa/3.0/) and GFDL. Treat compiled lexicon fields as derivative data under the ShareAlike terms applied to this directory.

## Audio

Pronunciation audio is synthesized at build time with the German **thorsten** Piper voice (CC0, [Thorsten Müller](https://github.com/thorstenMueller)). Piper’s tooling runs only on the author machine and is not shipped with the app.
